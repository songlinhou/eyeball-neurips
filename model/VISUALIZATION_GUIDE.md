# Attention Visualization Guide

This guide explains how to visualize the important frames and attention heatmaps generated by the multiclass model.

## Overview

The multiclass model (`ExplainableOpticalFlowResNet3D`) generates:
1. **Frame Importance Scores**: Temporal attention weights for each frame
2. **Spatial Attention Maps**: Heatmaps showing which regions the model focuses on
3. **Important Frames**: Top-K frames selected based on importance scores

## Visualization Scripts

### 1. Quick Visualization (`quick_visualize.py`)

**Purpose**: Fast, interactive visualization of a single sample

**Usage**:
```bash
# Visualize sample 0 (display in window)
python quick_visualize.py \
    --checkpoint checkpoints/multiclass_20260503/best_model_weights.pth \
    --sample_idx 0

# Visualize sample 5 and save to file
python quick_visualize.py \
    --checkpoint checkpoints/multiclass_20260503/best_model_weights.pth \
    --sample_idx 5 \
    --save visualizations/sample_5.png

# Show top-3 frames instead of top-5
python quick_visualize.py \
    --checkpoint checkpoints/multiclass_20260503/best_model_weights.pth \
    --sample_idx 10 \
    --top_k 3
```

**Output**:
- Main figure with 3 rows:
  - Row 1: Original important frames
  - Row 2: Attention heatmaps
  - Row 3: Heatmap overlays
- Timeline plot showing frame importance over time

**Example Output**:
```
Sample: 164267_02030
Ground Truth: non_rd / normal
Prediction: non_rd (98.5%) / normal (96.2%)

Top-5 important frame indices: [5, 12, 18, 24, 30]
```

## Understanding the Visualizations

### Frame Importance Timeline

The timeline plot shows:
- **Blue line**: Importance score for each frame (0-1 range)
- **Red stars**: Top-K selected frames
- **Red dashed lines**: Vertical markers at selected frame positions

**Interpretation**:
- Higher scores = more diagnostically important
- Peaks often correspond to key diagnostic moments
- Selected frames capture the most informative temporal segments

### Attention Heatmaps

The heatmaps show spatial attention:
- **Red/Yellow**: High attention (important regions)
- **Blue/Purple**: Low attention (less important)
- **Overlay**: Heatmap blended with original frame (60% frame + 40% heatmap)

**Interpretation**:
- Model focuses on anatomically relevant structures
- For retinal detachment: attention on detached retinal layers
- For normal cases: attention on intact retinal boundaries

### Prediction Confidence

Each visualization shows:
- **Ground Truth (GT)**: Actual diagnostic and subtype labels
- **Prediction (Pred)**: Model's prediction with confidence scores
- **Confidence**: Softmax probability (higher = more confident)

## Common Use Cases

### 1. Verify Model Attention is Correct

**Goal**: Check if the model focuses on clinically relevant regions

```bash
python quick_visualize.py \
    --checkpoint best_model.pth \
    --sample_idx 0
```

**What to look for**:
- ✅ Attention on retinal layers, vitreous cavity, optic nerve
- ❌ Attention on image borders, artifacts, or irrelevant regions

---

### 2. Analyze Misclassifications

**Goal**: Understand why the model made incorrect predictions

```bash
# Visualize multiple samples to find misclassifications
python visualize_attention.py \
    --checkpoint best_model.pth \
    --num_samples 20 \
    --output_dir visualizations/analysis
```

**Analysis**:
1. Find samples where `GT ≠ Pred`
2. Check if attention is on correct anatomical structures
3. Look for ambiguous cases or data quality issues

---

### 3. Create Figures for Papers/Presentations

**Goal**: Generate publication-quality visualizations

```bash
# High-resolution comparison grid
python visualize_attention.py \
    --checkpoint best_model.pth \
    --comparison_grid \
    --num_samples 4 \
    --top_k 5 \
    --output_dir paper_figures
```

**Tips**:
- Use `--comparison_grid` for side-by-side comparisons
- Select diverse samples (different diagnoses, subtypes)
- Increase DPI in code if needed (default: 150)

---

### 4. Debug Model Behavior

**Goal**: Understand temporal attention patterns

```bash
# Visualize with different top_k values
python quick_visualize.py --checkpoint best_model.pth --sample_idx 5 --top_k 3
python quick_visualize.py --checkpoint best_model.pth --sample_idx 5 --top_k 7
python quick_visualize.py --checkpoint best_model.pth --sample_idx 5 --top_k 10
```

**Analysis**:
- Compare how frame selection changes with different K
- Check if additional frames add diagnostic value
- Verify temporal consistency

## Customization

### Modify Heatmap Colormap

Edit `visualize_attention.py` or `quick_visualize.py`:

```python
# Change from 'jet' to other colormaps
im = ax.imshow(attention, cmap='viridis')  # or 'hot', 'plasma', 'turbo'
```

### Adjust Overlay Transparency

```python
# In apply_heatmap_overlay function
overlay = (1 - alpha) * frame + alpha * heatmap  # alpha=0.5 default

# More frame visible (alpha=0.3)
overlay = 0.7 * frame + 0.3 * heatmap

# More heatmap visible (alpha=0.7)
overlay = 0.3 * frame + 0.7 * heatmap
```

### Change Figure Size

```python
# In visualization functions
fig = plt.figure(figsize=(20, 12))  # Increase for larger output
```

## Programmatic Usage

### Use in Jupyter Notebook

```python
from visualize_attention import visualize_sample
from multiclass_model import create_multiclass_model
from erdes_dataset import ERDESDataset
import torch

# Load model
device = torch.device('cuda')
model = create_multiclass_model()
model.load_state_dict(torch.load('best_model.pth'))
model = model.to(device)

# Load dataset
dataset = ERDESDataset(
    csv_path='../benchmarks/input/balanced_split_desc.csv',
    data_root='../erdes',
    split='test',
    use_augmentation=False
)

# Visualize sample
video, labels, metadata = dataset[0]
visualize_sample(model, video, labels, metadata, device, output_path='sample.png')
```

### Extract Attention Programmatically

```python
import torch

# Get attention without visualization
model.eval()
video = video.unsqueeze(0).to(device)

with torch.no_grad():
    outputs = model(video)
    important_frames, frame_indices, importance_scores, important_attention = \
        model.get_important_frames(video, top_k=5)

# Access data
print(f"Frame indices: {frame_indices[0].cpu().numpy()}")
print(f"Importance scores shape: {importance_scores.shape}")  # (B, T)
print(f"Attention maps shape: {important_attention.shape}")  # (B, K, 1, H, W)
```

## Troubleshooting

### Issue: "CUDA out of memory"

**Solution**: Use CPU or reduce batch size
```bash
python visualize_attention.py \
    --checkpoint best_model.pth \
    --device cpu \
    --batch_size 1
```

### Issue: "FileNotFoundError: Video not found"

**Solution**: Check data_root path
```bash
python quick_visualize.py \
    --checkpoint best_model.pth \
    --data_root /correct/path/to/erdes \
    --sample_idx 0
```

### Issue: Visualization window doesn't appear

**Solution**: Save to file instead
```bash
python quick_visualize.py \
    --checkpoint best_model.pth \
    --sample_idx 0 \
    --save output.png
```
