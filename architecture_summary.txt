┌─────────────────────────────────────────────────────────────────────────┐

│  ├─ x_mixed = λ * x1 + (1-λ) * x2                                      │
│  └─ y_mixed = λ * y1 + (1-λ) * y2                                      │
│                                                                          │
│  Benefits:                                                               │

│  • Reduces overfitting                                                  │

================================================================================
                              LOSS FUNCTIONS
================================================================================

FOCAL LOSS (Recommended for Imbalanced Data)
┌─────────────────────────────────────────────────────────────────────────┐
│  FL(pt) = -αt * (1 - pt)^γ * log(pt)                                   │
│                                                                          │
│  Where:                                                                  │
│  • pt = probability of correct class                                    │
│  • αt = class weight (from dataset statistics)                         │
│  • γ = focusing parameter (default: 2.0)                                │
│                                                                          │
│  Behavior:                                                               │
│  • Easy examples (pt → 1): Low loss weight                             │
│  • Hard examples (pt → 0): High loss weight                            │
│  • Automatically handles class imbalance                                │
│                                                                          │
│  Benefits:                                                               │
│  • Focuses training on difficult cases                                  │
│  • Improves minority class performance                                  │
│  • Better than standard CrossEntropy for imbalanced data                │
└─────────────────────────────────────────────────────────────────────────┘
